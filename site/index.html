A menu bar app for Mac

Make a face. Get the meme.

MemeMe lives in your menu bar, with no Dock icon and no window. Press ⌃⌘M in any chat, make the face you mean, and copy the reaction that matches.

    Install

    You do this once. After that, MemeMe updates itself.

    The camera is on only while the panel is open, and your face never leaves your Mac.

    GIFs need a free GIPHY API key for now. Add it with Set GIPHY API Key… in the smiley menu.

    1. Drag it to Applications

      Open MemeMe.dmg and drag MemeMe to Applications.

    2. Open it the first time

      MemeMe isn’t notarized by Apple yet, so the first open needs one extra step.

      macOS 15 or later
      System Settings → Privacy & Security → Open Anyway
      macOS 14
      Control-click MemeMe → Open → Open

    3. Allow the camera

      Then press ⌃⌘M in any chat.
